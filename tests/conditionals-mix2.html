Микс First и Second Conditional: правило, 3 упражнения и практика

🔵 First Conditional

Реальные, вероятные ситуации в будущем.

If + Present Simple, will + infinitive

If it rains, we will stay at home.

🩷 Second Conditional

Воображаемые, маловероятные ситуации.

If + Past Simple, would + infinitive

If I won the lottery, I would buy a house.

❗ Ни will, ни would не ставим в if-clause. If I were you… — всегда were.
