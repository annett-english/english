First Conditional

Возможная ситуация и её результат. Шесть упражнений с проверкой, ответами и объяснениями, лексика про характер, одежду и дела по дому.

If + present→will / won't + infinitive

Rule · Правило

How it works

  1. 1

    We use if + present to talk about a possible situation and will / won't + infinitive to talk about the consequence.

    If + настоящее время — для возможной ситуации, will / won't + инфинитив — для её последствия.

    If you don't go, she won't be very pleased.

  2. 2

    The if-clause can come first or second. If the if-clause comes first, we usually put a comma before the next clause.

    If-часть может быть первой или второй. Если она первая, обычно ставим запятую.

    If you don't go, she won't be very pleased.She won't be very pleased if you don't go.

  3. 3

    We can also use the imperative or can + infinitive instead of will + infinitive in the other clause.

    Вместо will + инфинитив можно использовать повелительное наклонение или can + инфинитив.

    If you miss the last bus, get a taxi.If you miss the last bus, you can get a taxi.

жёлтый — if-часть (условие)синий — результат

Главная ловушка: после if не ставим will. Говорим If it rains, а не If it will rain.
