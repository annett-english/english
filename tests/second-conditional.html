Тренажёр по Second Conditional: 9 заданий, проверка и ответы с объяснениями

📘 Правило (нажми, чтобы свернуть)

1. Формирование и использование

Для воображаемых или гипотетических ситуаций в настоящем или будущем.
If + Past Simple, would / wouldn’t + infinitive

If I had more money, I would travel more.
If I lived abroad, I wouldn’t miss winter.

2. Порядок частей

If-clause может стоять в начале или в конце. В начале — ставим запятую.

If I won the lottery, I would buy a house.
I would buy a house if I won the lottery.

3. Could вместо would

could + infinitive выражает возможность: If I had more free time, I could learn Italian.

4. If и would не живут вместе

❌ If I would have more money…
✅ If I had more money…

5. Was or were?

С глаголом be после I / he / she / it можно was или were: If I was / were rich, I’d travel more.

6. If I were you…

Всегда were, не was. Так даём совет: If I were you, I’d talk to him.
