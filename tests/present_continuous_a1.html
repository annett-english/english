⏳ Present Continuous — уровень A1

Present Continuous используется для действий, которые происходят прямо сейчас, в момент речи.

Формула:
(+) subject + am / is / are + verb-ing
(−) subject + am / is / are + not + verb-ing
(?) Am / Is / Are + subject + verb-ing ?

Слова-маркеры: now, right now, at the moment
Глаголы: leave home, start work, get up, finish work, have lunch, watch TV, get home, go to bed, make
