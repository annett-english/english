Правило

Три типа условных предложений — от факта к фантазии.

Zero Conditional — реальный факт

If/When + Present Simple, ... Present Simple

Используется для законов природы, научных фактов и привычных, всегда верных вещей. «If» здесь можно свободно заменить на «When» — смысл не меняется, потому что речь не о конкретном случае, а о правиле.

If you heat ice, it melts. = When you heat ice, it melts.

First Conditional — реальное будущее условие

If + Present Simple, ... will + V (infinitive)

Условие вполне реально и относится к будущему. Главная ошибка учащихся — ставить «will» и после «if» тоже. Правило простое: после if/его заменителей — только Present Simple, «will» — только в главной части.

If it rains tomorrow, we will stay at home.

Чем можно заменить «if» в First Conditional

unless = if... not. После него, как и после «if», идёт Present Simple, а «will» остаётся только в главной части.

Unless you hurry, you'll be late. = If you don't hurry, you'll be late.

Second Conditional — нереальное/гипотетическое условие

If + Past Simple, ... would + V (infinitive)

Ситуация вымышленная, маловероятная или прямо противоречит настоящему. В формальном и «правильном» варианте для всех лиц (включая I/he/she/it) используется were, а не «was» — хотя в разговорной речи «was» тоже встречается.

If I were you, I would apologise.  ·  If I had more time, I would learn Italian.

Упражнение 1

Choose the correct answer — выберите правильную форму.

Упражнение 2

Find the mistake — в предложении есть ошибка. Выберите вариант, который её правильно исправляет.

Упражнение 3

Fill in the gaps using the correct form — впишите глагол в нужной форме.

Упражнение 4

What usually comes after? — какая часть предложения логично и грамматически продолжает if-clause?

Упражнение 5

Change the tense/person — перестройте предложение по инструкции (тип условного и/или лицо).

Дриллинг: Repeat & Change

По образцу придумайте свои предложения. Меняйте подлежащее, глаголы, тему — механика конструкции должна остаться такой же. Когда закончите — скопируйте все ответы одной кнопкой.

Zero Conditional

Model: If you don't sleep enough, you feel tired.

First Conditional

Model: If I have free time this weekend, I will read a book.

Second Conditional

Model: If I won a trip anywhere, I would go to Japan.
