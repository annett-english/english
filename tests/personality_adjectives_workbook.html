Повторение слов

Прослушай каждое слово (кнопка 🔊), проговори вслух и вспомни перевод, прежде чем переходить к упражнениям.

Заполнено полей: 0 / 0

Упражнение 1. Вставь пропущенные буквы

Впиши слово полностью, восстановив пропущенные буквы.

Упражнение 2. Unscramble the word

Собери слово из перемешанных букв.

Упражнение 3. Перевод: русский → английский

Напиши английское прилагательное по русскому переводу.

Упражнение 4. Прописать слово по звуку (Listen & write)

Нажми 🔊, прослушай произношение и запиши слово, которое услышал(а).

Упражнение 5. Definition → word

По определению на английском напиши нужное прилагательное.

Упражнение 6. Explain the difference

Объясни на английском, чем отличаются два слова в паре. Открытое задание — сравни свой ответ с образцом.

Упражнение 7. Вставь слово в текст по контексту

Заполни пропуск подходящим прилагательным из списка слов.

Упражнение 8. Rephrase

Перефразируй предложение так, чтобы использовать указанное прилагательное. Открытое задание.

Упражнение 9. Expand the sentence

Расширь короткое предложение: добавь детали, причину или пример. Открытое задание.

Упражнение 10. Напиши своё предложение

Составь собственное предложение с указанным словом. Открытое задание — образец даётся только для сравнения.
