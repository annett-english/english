📘 Краткое правило (нажмите, чтобы свернуть)
Conditional 1 — реальное будущее
If + Present Simple, ... will + verb
Используем, когда условие вполне реально выполнимо.
If she applies for the job, she will get an interview.
Conditional 2 — нереальное настоящее/будущее
If + Past Simple (were для всех лиц), ... would + verb
Гипотетическая, маловероятная или воображаемая ситуация сейчас.
If I were you, I would resign.
Conditional 3 — нереальное прошлое
If + Past Perfect, ... would have + V3
Сожаление или гипотеза о прошлом, которое уже нельзя изменить.
If she had studied harder, she would have got a better degree.
