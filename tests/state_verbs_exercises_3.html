State Verbs — часть 3

6 упражнений по 10 заданий

Напоминание: State Verbs описывают состояние, а не действие, и обычно не используются в Continuous. Сюда входят чувства и предпочтения (like, love, wish, prefer), органы чувств (see, hear, taste, smell), восприятие/мышление (know, believe, understand, remember, recognise, notice, forget) и другие (be, have, contain, include, belong, need, cost, mean, own, require, resemble, weigh, fit, keep). Многие из них меняют значение и переходят в Continuous, когда описывают действие (have = завтракать, see = встречаться, think = обдумывать, expect = ждать ребёнка, weigh/fit = взвешивать/устанавливать).
