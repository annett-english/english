So do I / Neither do I

Тренажёр по согласию с утверждениями — 5 упражнений, 40 заданий

Правило

Положительное согласие («я тоже»): So + вспом. глагол + подлежащее — So do I, So am I, So can I. Порядок слов обратный (инверсия). Второй вариант: подлежащее + вспом. глагол + too — I do too.

Отрицательное согласие («я тоже нет»): Neither/Nor + вспом. глагол + подлежащее — Neither do I, Neither am I. Второй вариант: подлежащее + not + вспом. глагол + either — I don't either, I'm not either.

Вспомогательный глагол выбирается по тому, что было в исходной фразе, и согласуется с новым подлежащим: be → am/is/are/was/were; do → do/does/did; have → have/has/had; модальные — без изменений (can, will, must, would…).
