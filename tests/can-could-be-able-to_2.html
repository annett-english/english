Кратко о правиле

can и could — модальные глаголы. У них есть только форма настоящего (can, может использоваться и для будущего) и форма прошедшего/условного времени (could). Во всех остальных формах (инфинитив, герундий, перфект, будущее, после других модальных глаголов) вместо них используется be able to.

ЗначениеФормаПример
Настоящая способность / разрешениеcan / can'tI can swim.
Общая способность в прошломcould / couldn'tShe could read at four.
Конкретное достижение в прошлом (утв.)was/were able to (не could)We were able to land safely.
Отрицание конкретного случая в прошломcouldn't / wasn't able toHe couldn't open the door.
Будущееwill be able toYou'll be able to drive next year.
После модальных (may, must, might…)be able toHe might be able to help.
Инфинитив / герундий / перфектto be able to / being able to / have been able toI'd love to be able to sing.
Формальный стиль в present/pastam/is/are able to; was/were able toI am able to accept your invitation.
