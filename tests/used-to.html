📌 Правило

  • Форма: used to / didn't use to (never used to) + V1. Вопрос: Did … use to …? (только прошлое!)
  • Когда: прошлые привычки и состояния, которых сейчас нет: I used to be shy.
  • Past Simple — если есть точная дата, число раз или действие было один раз: We went to the cinema on Saturday.
  • any more / any longer = «больше не»: I don't go to the gym any more.
