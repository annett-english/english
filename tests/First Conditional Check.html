First Conditional Check

Короткая проверка только на First Conditional: форма, порядок частей, won't, imperative и can.

If + present→will / won't + infinitive
If-часть первая — запятая: If it rains, we will stay. Вторая — без запятой: We will stay if it rains. Вместо will можно: imperative (call me) или can + infinitive. После if will не ставим.
