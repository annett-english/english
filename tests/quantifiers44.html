🍎 Quantifiers

a / an · some · any · a lot of · числа — уровень A1–A2

Правило (нажми, чтобы открыть)
a / anтолько исчисляемые, ед. число: a banana, an apple
числаисчисляемые, мн. число: four apples
someобычно в утверждениях: I’d like some pasta.
anyвопросы и отрицания: I can’t see any potatoes.
a lot ofс исчисляемыми (мн.) и неисчисляемыми: a lot of rice
неисчисл.глагол в ед. числе: This pasta is delicious.
